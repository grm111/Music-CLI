# MusicCLI

A command-line music player written in Rust. Currently a work in progress.

## Features
- Command-line arguments for fuzzy and normal song search
- Global hotkeys for playback and audio effects
- Independent pitch, speed, and reverb adjustment
- Audio processing and playback using Rodio, Rubber Band, and Freeverb
- Inter-process communication between the CLI and audio engine

## Planned Features
- Audio visualizer
- Recording
- Radio
- Music library management and local song discovery
